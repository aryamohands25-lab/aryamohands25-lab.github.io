Personal portfolio website of **Arya Mohan G.** — MSc Data Science & Bio-AI student with a BSc in Chemistry, working at the intersection of Data Science, AI, Machine Learning and Bio-AI.

## About the site

A single-page, responsive portfolio with dark/light mode, an interactive particle network that reacts to the cursor, and sections for:

- About, Skills and Projects
- Where Science Meets Intelligence (interactive Bio-AI pipeline)
- DevOps and MLOps
- Journey, Certifications and Resume
- Contact

## Featured projects

- **DataDock AI** – version-aware data quality and regression monitoring platform (FastAPI, PostgreSQL, React/Next.js, Docker)
- **IntelliVault** – personal knowledge assistant using AI agents and RAG
- **Multi-Target Polypharmacology Generator** – dual-pocket 3D diffusion with RL fine-tuning
- **CADD for Parkinson's Disease (LRRK2)** – QSAR pipeline with virtual screening
- Healthcare missing-value imputation, molecular classification with SHAP, DNA methylation analysis, and more
